# MotionFit

MotionFit is a local-first workout experience built as a static PWA.

Exercise data by [RepDB (repdb.co)](https://repdb.co). The curated 55-exercise MotionFit V1 library uses RepDB as its primary exercise-data and illustration source, with concise Spanish coaching cues and equipment-specific matching.
